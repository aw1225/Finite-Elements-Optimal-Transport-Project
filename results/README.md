# Results Directory

This directory should contain only compact, curated results suitable for Git.

Allowed examples:

- small CSV summaries used directly in thesis tables;
- derived summary JSON files;
- text provenance records;
- small figure thumbnails if needed for README documentation.

Excluded examples:

- raw solver result directories;
- rank-split map CSV exports;
- VTK/VTP/PVD field payloads;
- tarballs and zip archives;
- PBS stdout/stderr files.

Large evidence lives outside Git and is indexed in `docs/evidence-archive-index.md`.
