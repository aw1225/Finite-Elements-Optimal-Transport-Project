# Experiment Families

This directory is a lightweight index of the experiment families used by the thesis. Full result archives are stored outside Git and listed in `docs/evidence-archive-index.md`.

## Core benchmark families

- `translation`: disk translation benchmark and translation reference-validation runs.
- `hierarchy-refinement`: bridge hierarchy, heat-substep, and periodic-width robustness checks.
- `stress-tests`: T1--T5 frozen stress-test suite and supplemental diagnostics.

## Chapter-level role

- Chapter 4 establishes finite-element heat-kernel Sinkhorn behavior and reference validation.
- Chapter 5 studies nonlinear multilevel FAS acceleration, cost accounting, and stress-test transfer.
- Post-review controls refine robustness claims and add map-visualization evidence.

## What belongs here

Keep this directory for small experiment definitions, parameter tables, and exact command templates. Do not store raw solver output here.
