# Stress-Test Drivers

Frozen stress-test drivers for the T1--T5 transfer experiments.

- `t1`: nonlinear crescent.
- `t2`: split half-disks.
- `t3`: disk-to-annulus.
- `t4`: high-frequency square.
- `t5`: thin-neck exploratory/deployable extension.

These files are included for code reading and provenance. Large outputs and map fields are indexed as external evidence archives rather than committed here.
