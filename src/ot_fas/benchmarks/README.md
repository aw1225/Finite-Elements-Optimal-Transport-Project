# Benchmark Drivers

Curated benchmark drivers for the thesis companion repository.

- `translation/`: translation exact-error and discrete-reference drivers.
- `affine/`: affine rotated-map robustness and post-review controls.
- `annulus/`: annulus FMG/FAS benchmark driver.

These are historical scientific drivers, kept close to their executed form. They may contain CX3-specific defaults and should be read together with `docs/curated-source-manifest.csv`.
