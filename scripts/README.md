# Scripts

This directory is reserved for small utility scripts used to inspect, collect, or convert thesis evidence.

Expected script types:

- checksum and manifest helpers;
- compact collector scripts for archived result folders;
- CSV-to-VTP conversion scripts for map visualization;
- small table-generation utilities.

Scripts should be deterministic, accept paths as arguments where possible, and avoid hard-coding private scratch locations unless the file is explicitly marked as a historical CX3 wrapper.
